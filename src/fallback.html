fog UI not built

This binary was built without the bundled SPA (ui/dist missing at compile time). API endpoints (/api/*, /logs/stream) still work, but the web UI cannot be served.

Fix (one-time, from repo root): 
cd ui && pnpm install && pnpm build
cargo build --release
# or for a git install:
cargo install --git https://github.com/Naputt1/fog.git --tag v0.1.0
# prebuilt SPA is included in crates.io releases (fog-tui)

If you installed via cargo install --git on main without a tag, the build script will try to fetch the SPA from the latest GitHub Release. To skip the network attempt:

FOG_SKIP_SPA_DOWNLOAD=1 cargo install --git https://github.com/Naputt1/fog.git

After rebuilding, open http://127.0.0.1:18080/ again.
